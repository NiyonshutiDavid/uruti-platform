
  # Uruti Web Platform

  Welcome to the Uruti Web Platform frontend module. This repository contains the user interface and client-side logic for the Uruti Platform application.

  ## Project Overview

  - **Module**: Uruti Web Frontend

  ## Getting Started

  ### Prerequisites
  - Node.js (v14 or higher)
  - npm or yarn

  ### Installation

  Install project dependencies:
  ```bash
  npm i
  ```

  ### Development

  Start the development server:
  ```bash
  npm run dev
  ```

  The application will be available at `http://localhost:3000` (or your configured port).

  ### Building for Production

  ```bash
  npm run build
  ```
